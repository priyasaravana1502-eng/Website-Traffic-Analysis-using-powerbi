# Website Traffic Analysis using Power BI

## Project Overview
This project analyses website traffic data using Microsoft Power BI.

## Objective
- Analyse users and sessions
- Identify traffic sources
- Evaluate engagement metrics
- Create an interactive dashboard
- Generate business insights

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- Microsoft Word

## Dashboard Features
- Total Users KPI
- Total Sessions KPI
- Event Count Analysis
- Engagement Rate Analysis
- Traffic Channel Analysis
- Interactive Filters

## Files Included
- Power BI Dashboard
- Dataset
- Project Report
- Dashboard Screenshot
